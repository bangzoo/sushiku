Kamu adalah ARSITEK UTAMA aplikasi web bernama "SushiKu" —

aplikasi manajemen bisnis sushi rumahan yang dibangun sebagai
Progressive Web App (PWA) sehingga bisa diakses dan di-install
langsung dari iPhone Safari tanpa App Store.

KONTEKS BISNIS (selalu ingat ini):
- Nama bisnis    : Bisnis Sushi (nama bisa diganti user nanti)
- Jenis usaha    : Jualan sushi dari rumah, baru mulai
- Pemilik        : 1 orang (solo, tidak ada partner/karyawan)
- Channel order  : WhatsApp + walk-in langsung di rumah
- Pembayaran     : Campuran cash + transfer bank/QRIS
- Platform       : PWA — harus optimal di iPhone Safari & Android Chrome
- Tujuan app     : Bantu pemilik kelola semua aspek bisnis sushi
                   dari 1 app: kasir, stok, keuangan, laporan,
                   manajemen order WhatsApp, sampai analisis bisnis

IDENTITAS & PERAN KAMU:

- Senior Full-Stack Web Developer (Next.js 14, TypeScript, Tailwind)

- UX Designer yang paham kebutuhan UMKM Indonesia
- Akuntan yang paham pembukuan usaha kecil
- Business Analyst yang paham bisnis F&B rumahan Indonesia

   dan bisa di-install ke home screen (manifest + service worker)

8. Selalu ingat konteks dari tahap-tahap sebelumnya

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Bangun fondasi yang solid untuk SushiKu PWA.

1. STRUKTUR FOLDER NEXT.JS 14
   Buat folder structure lengkap App Router yang mencakup
   semua 8 fitur. Sertakan penjelasan fungsi setiap folder.

2. PACKAGE.JSON
   Semua dependencies yang dibutuhkan untuk seluruh project
   dengan versi yang kompatibel.

3. PWA SETUP LENGKAP
   A. manifest.json:
      - name, short_name, description
      - icons: semua ukuran (72, 96, 128, 144, 152, 192, 384, 512)
      - apple-touch-icon untuk setiap ukuran iPhone
      - theme_color, background_color, display: standalone
      - start_url, scope, orientation: portrait
   
   B. next.config.js dengan next-pwa:
      - Service worker setup
      - Cache strategy: network-first untuk API, cache-first untuk assets
      - Offline fallback page
   
   C. Meta tags di layout.tsx untuk iOS:
      - apple-mobile-web-app-capable: yes
      - apple-mobile-web-app-status-bar-style: black-translucent
      - apple-mobile-web-app-title
      - Splash screen untuk iPhone 14, 13, 12, SE
   
   D. Instruksi "Add to Home Screen" untuk user:
      Komponen InstallPrompt.tsx yang muncul pertama kali buka
      di Safari, menjelaskan cara install ke home screen iPhone

4. DATABASE SCHEMA SUPABASE (LENGKAP)
   SQL migration untuk semua tabel:

   A. menu_items (menu sushi)
      (id, nama, deskripsi, harga_jual, harga_modal, kategori,
       foto_url, tersedia: boolean, urutan_tampil, created_at)
      Kategori: 'nigiri'|'maki'|'sashimi'|'roll'|'set_menu'|
                'minuman'|'tambahan'

   B. orders (transaksi)
      (id, nomor_order, tanggal, waktu, tipe: 'walkin'|'whatsapp',
       nama_customer, nomor_wa, items_json, catatan_order,
       total_harga, metode_bayar: 'cash'|'transfer'|'qris',
       status: 'pending'|'proses'|'selesai'|'batal',
       dibayar: boolean, created_at)

   C. order_items (detail item per order)
      (id, order_id, menu_item_id, nama_item, harga_satuan,
       jumlah, catatan_item, subtotal)

   D. bahan_baku (stok bahan)
      (id, nama, satuan, stok_sekarang, stok_minimum,
       harga_per_satuan, kategori, created_at, updated_at)

   E. stok_log (riwayat perubahan stok)
      (id, bahan_baku_id, jenis: 'masuk'|'keluar'|'koreksi',
       jumlah, keterangan, harga_total, created_at)

   F. pengeluaran (semua pengeluaran)
      (id, tanggal, kategori: 'bahan_baku'|'operasional'|
       'kemasan'|'transport'|'promosi'|'lain',
       keterangan, jumlah, bukti_url, created_at)

   G. pemasukan_lain (pemasukan selain penjualan)
      (id, tanggal, keterangan, jumlah, created_at)

   H. customers (data pelanggan)
      (id, nama, nomor_wa, alamat, total_order, total_belanja,
       pertama_order, terakhir_order, catatan, created_at)

   I. daily_summary (rekap harian otomatis)
      (id, tanggal, total_order, total_omzet, total_cash,
       total_transfer, hpp_total, laba_kotor, pengeluaran_operasional,
       laba_bersih, created_at)

   Sertakan: indexes, RLS policies, triggers untuk auto-update
   daily_summary dan customers stats.

5. DEXIE.JS SETUP (IndexedDB untuk offline)
   File lib/db.ts:
   - Mirror schema utama untuk offline: orders, order_items,
     menu_items, pengeluaran
   - Sync queue: tabel untuk antri data yang belum ter-sync
   - Fungsi syncToSupabase() yang jalan saat online kembali

6. KONSTANTA & TYPES GLOBAL
   - constants/index.ts: warna, kategori menu, kategori pengeluaran,
     format Rupiah, pesan WhatsApp template
   - types/index.ts: semua TypeScript interface

7. SAMPLE DATA
   SQL INSERT untuk menu sushi awal (minimal 15 item realistis):
   - Nigiri: Salmon, Tuna, Ebi, Tamago (harga & modal realistis)
   - Maki: California Roll, Salmon Roll, Vegetable Roll
   - Sashimi: Salmon 5pcs, Tuna 5pcs
   - Set Menu: Set A (10pcs mix), Set B (15pcs mix)
   - Minuman: Green Tea, Ocha, Air Mineral
   - Tambahan: Wasabi extra, Gari extra, Soy Sauce extra

TAHAP 3 — KASIR & CATAT ORDER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Lanjut Tahap 3. Ini core feature utama — sistem kasir untuk
catat order walk-in dan order WhatsApp. Target: selesai dalam < 15 detik.

1. HALAMAN KASIR (/kasir)
   Layout 2 bagian:
   
   ATAS — GRID MENU:
   - Tampil semua menu yang tersedia sebagai card touchable
   - Tap = langsung tambah 1 ke keranjang dengan animasi
   - Long press = modal pilih jumlah (1-50)
   - Badge counter di pojok card kalau sudah ada di keranjang
   - Filter kategori (horizontal scroll chip)
   - Search menu (untuk kalau menu sudah banyak)
   - Menu tidak tersedia: tampil redup, tidak bisa di-tap
   
   BAWAH — KERANJANG (sticky bottom panel):
   - Jumlah item + total harga
   - Tap panel → expand jadi full screen keranjang
   - Di keranjang: list item, quantity +/-, hapus item, catatan per item
   - Tombol [Bayar Sekarang] warna merah besar

2. PILIH TIPE ORDER (muncul sebelum keranjang)
   Saat pertama tap menu, pilih dulu:
   [🚶 Walk-in] [📱 WhatsApp Order]
   
   Walk-in: langsung ke kasir, nama customer opsional
   WhatsApp: wajib isi nama + nomor WA customer

3. LAYAR PEMBAYARAN
   - Tampil total besar dan jelas
   - Pilih metode: [💵 Cash] [🏦 Transfer] [📱 QRIS]
   - Jika cash: input "Uang diterima" → auto hitung kembalian
   - Jika transfer/QRIS: tampil info rekening (dari settings)
     + tombol "Konfirmasi Sudah Dibayar"
   - Catatan order (opsional)
   - Tombol [Selesaikan Order]
   - Setelah selesai: animasi sukses + konfeti kecil

4. STRUK DIGITAL
   Setelah order selesai, tampil struk digital:
   - Nomor order, tanggal, jam
   - List item + qty + subtotal
   - Total, metode bayar, kembalian (jika cash)
   - Nama bisnis + ucapan terima kasih
   - Tombol [Kirim ke WhatsApp Customer]
     (auto buka WA dengan pesan struk yang sudah diformat)
   - Tombol [Order Baru] untuk reset kasir

5. KIRIM STRUK VIA WHATSAPP
   Format pesan WhatsApp otomatis:
   "🍣 *[Nama Bisnis Sushi]*
   
   Halo [Nama Customer]! 
   Terima kasih sudah order ya 😊
   
   📋 *Detail Order #[nomor]*
   [item] x[qty] — Rp [harga]
   ...
   ─────────────────
   💰 *Total: Rp [total]*
   💳 Bayar via: [metode]
   
   Pesanan sedang disiapkan!
   Est. selesai: 15-20 menit 🍱"
   
   Tap tombol → buka WhatsApp langsung ke nomor customer

6. ANTRIAN ORDER (ORDER QUEUE)
   Halaman /antrian — tampil semua order yang status "proses":
   - Card per order: nomor, nama customer, item summary, waktu order
   - Warna berdasarkan lama tunggu:
     * < 15 menit: hijau
     * 15-30 menit: kuning
     * > 30 menit: merah (perlu diprioritaskan)
   - Tap card → lihat detail + tombol [Tandai Selesai]
   - Notif push saat ada order WhatsApp baru masuk

7. RIWAYAT ORDER (/riwayat)
   - List semua order, terbaru di atas
   - Filter: hari ini, minggu ini, bulan ini, semua
   - Filter tipe: walk-in / WhatsApp / semua
   - Search by nama customer atau nomor order
   - Setiap item: nomor, waktu, customer, total, status, metode bayar
   - Tap → detail order lengkap + opsi batalkan (dengan alasan)

8. OFFLINE SUPPORT
   Kasir harus tetap bisa dipakai tanpa internet:
   - Data menu tersimpan di IndexedDB (Dexie.js)
   - Order tersimpan lokal dulu jika offline
   - Indikator "Offline Mode" di header saat tidak ada koneksi
   - Auto-sync semua data saat koneksi kembali
   - Konflik sync: last-write-wins dengan timestamp

Lanjut Tahap 4. Bangun sistem manajemen stok bahan baku sushi.

1. HALAMAN STOK (/stok)
   - List semua bahan baku dengan stok sekarang
   - Warna indikator stok:
     * Hijau: stok aman (> stok minimum × 2)
     * Kuning: stok menipis (antara minimum dan minimum × 2)
     * Merah: stok kritis (≤ stok minimum) + badge "Perlu Beli!"
   - Sort: by nama, by stok kritis dulu, by kategori
   - Search bahan
   - Summary di atas: "X bahan kritis, Y bahan menipis"

2. FORM TAMBAH BAHAN BAKU
   Field:
   - Nama bahan (misal: Salmon fillet, Nori, Shari/nasi sushi)
   - Kategori: ikan/seafood, sayuran, bahan_dasar, bumbu, kemasan
   - Satuan: gram, kg, pcs, lembar, botol, pack
   - Stok awal (jumlah)
   - Stok minimum (batas alert)
   - Harga per satuan (untuk kalkulasi HPP)

3. UPDATE STOK
   Tombol [+ Stok Masuk] dan [- Stok Keluar] di setiap bahan:
   
   Stok Masuk (belanja bahan):
   - Jumlah yang dibeli
   - Harga beli total (auto hitung harga per satuan baru)
   - Tanggal beli
   - Keterangan (beli di mana)
   - Auto catat ke tabel pengeluaran kategori "bahan_baku"
   
   Stok Keluar (pemakaian):
   - Jumlah yang dipakai
   - Untuk order apa (opsional, link ke order)
   - Keterangan
   
   Koreksi Stok:
   - Jika ada selisih hitung fisik vs sistem
   - Wajib isi alasan koreksi

4. RIWAYAT STOK
   Per bahan: timeline masuk keluar dengan grafik mini
   Total stok masuk vs keluar bulan ini

5. ALERT STOK HABIS
   - Notifikasi push saat stok bahan turun ke level minimum
   - Halaman "Perlu Dibeli" — list semua bahan kritis
   - Tombol [Buat Daftar Belanja] → generate teks list belanja
     yang bisa langsung di-share via WhatsApp

6. KALKULASI HPP OTOMATIS
   Setiap menu sushi bisa di-link ke bahan baku:
   - Input: salmon roll butuh berapa gram salmon, berapa gram nori, dll
   - Sistem auto kalkulasi HPP berdasarkan harga bahan terkini
   - Update harga modal di menu secara otomatis
   - Tampil HPP aktual vs harga modal yang di-set manual

Lanjut Tahap 5. Bangun sistem pencatatan keuangan lengkap.

1. HALAMAN KEUANGAN (/keuangan)
   4 kartu summary di atas:
   - Pemasukan hari ini (dari penjualan)
   - Pengeluaran hari ini
   - Laba bersih hari ini
   - Saldo kas (cash di tangan)

2. CATAT PENGELUARAN
   Kategori pengeluaran:
   🛒 Bahan Baku (auto tercatat dari Tahap 4, bisa manual juga)
   📦 Kemasan (wadah, plastik, chopstick, soy sauce sachet)
   🔥 Operasional (gas, listrik, air)

3. CATAT PEMASUKAN LAIN

   - Modal tambahan yang dimasukkan
   - Pengembalian uang
   - Lain-lain
   Field: keterangan, jumlah, tanggal

4. REKAP HARIAN
   Halaman /keuangan/rekap:
   
   PEMASUKAN:
   - Penjualan cash   : Rp xxx
   - Penjualan transfer: Rp xxx
   - Pemasukan lain   : Rp xxx
   - TOTAL PEMASUKAN  : Rp xxx
   
   PENGELUARAN (per kategori):
   - Bahan baku       : Rp xxx
   - Kemasan          : Rp xxx
   - Operasional      : Rp xxx
   - Transport        : Rp xxx
   - Promosi          : Rp xxx
   - TOTAL PENGELUARAN: Rp xxx
   
   HASIL:
   - LABA BERSIH      : Rp xxx
   - Margin           : xx%

5. FORMULA KEUANGAN
   HPP Total = Total harga modal semua item terjual
   Laba Kotor = Total Omzet - HPP Total
   Laba Bersih = Laba Kotor - Pengeluaran Operasional
                - Kemasan - Transport - Promosi - Lain-lain
   Margin = (Laba Bersih / Total Omzet) × 100%

   - Header: nama bisnis + tanggal
   - Tabel pemasukan
   - Tabel pengeluaran per kategori
   - Ringkasan laba & margin
   - Share via WhatsApp atau simpan ke file

   - Line chart: laba bersih per hari
   - Hari terbaik minggu ini (omzet tertinggi)
   - Hari paling sepi (bisa jadi insight untuk promo)
   - Total minggu ini vs minggu lalu (naik/turun berapa %)
   - Rata-rata order per hari
   - Rata-rata nilai per order (Average Order Value)

2. LAPORAN BULANAN (/laporan/bulanan)
   - Grafik tren omzet per minggu dalam bulan
   - Pie chart: breakdown omzet per kategori menu
   - Pie chart: breakdown pengeluaran per kategori
   - Perbandingan bulan ini vs bulan lalu
   - Total order, total pelanggan unik, repeat customer %
   - Best seller bulan ini (top 5 menu)
   - Menu paling tidak laku (bottom 3)

3. ANALISIS MENU (/laporan/menu)
   Tabel ranking semua menu:
   - Nama menu | Qty terjual | Total omzet | Margin | Rating
   - Filter: minggu ini, bulan ini, semua waktu
   - Sort by: terlaris, omzet tertinggi, margin tertinggi
   - Rekomendasi AI sederhana (rule-based, tidak butuh Gemini):
     * Menu dengan margin > 50% tapi penjualan rendah → rekomendasikan promo
     * Menu yang tidak terjual 14 hari → pertimbangkan hapus dari menu
     * Menu terlaris dengan stok bahan kritis → alert segera beli bahan

4. ANALISIS WAKTU
   - Heatmap jam ramai: jam berapa paling banyak order
   - Hari dalam seminggu: hari apa paling ramai
   - Insight: "Order paling banyak masuk Jumat-Minggu jam 11-13"
   - Saran: "Siapkan bahan lebih banyak untuk akhir pekan"

5. ANALISIS PELANGGAN
   - Total pelanggan unik
   - Pelanggan baru vs pelanggan lama bulan ini
   - Top 5 pelanggan (by nilai belanja)
   - Rata-rata frekuensi order per pelanggan
   - Pelanggan yang sudah lama tidak order (> 30 hari)

6. TARGET & PENCAPAIAN
   Owner bisa set target bulanan:
   - Target omzet bulan ini: Rp xxx
   - Progress bar: sudah tercapai berapa %
   - Estimasi: "Dengan rata-rata sekarang, bulan ini akan mencapai Rp xxx"
   - Target laba bersih
   - Target jumlah order

7. EXPORT LAPORAN BULANAN PDF
   Laporan profesional yang bisa disimpan/share:
   - Cover page: nama bisnis + periode
   - Executive summary (ringkasan 1 halaman)

   - Grafik omzet & laba
   - Rekomendasi bisnis berdasarkan data
